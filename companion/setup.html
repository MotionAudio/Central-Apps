Set up Central Pedal

Three things, then Upload. The pedal does the rest.

1 Wi-Fi

The Wi-Fi the pedal uses at church.

2 Touch screen

The screen on the pedal. Most pedals have the blue 3.5" one. The pedal downloads its driver and restarts once.

3 4-digit code

If you use Central Control, type the main admin's code. If not, pick any 4 digits. Central Pedal Control uses this code to connect.
