Opening it the first time

The apps aren't signed with a paid Apple or Microsoft certificate yet, so your computer will ask once before it opens one. Here's what to press.

Windows says "Windows protected your PC"
  1. Click More info.
  2. Click Run anyway. It installs and opens by itself.
Mac says it can't be opened, or Apple couldn't check it
  1. Open the .dmg and drag the app into Applications.
  2. Open the app. The Mac will refuse the first time, so click Done.
  3. Go to System Settings → Privacy & Security, scroll down, click Open Anyway next to the app's name and confirm.
  4. When it asks to use the microphone, say yes. Your audio interface, the tuner and the instrument need it.

If the Mac says the app is damaged, open Terminal and run the line for that app.

xattr -dr com.apple.quarantine "/Applications/Central Control.app"
xattr -dr com.apple.quarantine "/Applications/CentralUsage.app"
xattr -dr com.apple.quarantine "/Applications/Central Pedal Control.app"
xattr -dr com.apple.quarantine "/Applications/Central Services.app"
xattr -dr com.apple.quarantine "/Applications/Central Production.app"
Android asks about installing unknown apps
  1. Open the .apk you downloaded, from Downloads or the browser's notification.
  2. Android asks if your browser can install apps. Tap Settings, turn on Allow from this source, go back and tap Install.
  3. Open the app while you're on the church Wi-Fi. In Central Usage, tap Find the main admin.
Linux
  1. The one-line install under each app is the easy way. Type your password when it asks. You can run the same line again later to reinstall.
  2. To install a .deb yourself, run sudo apt install ./<the file>.deb. The ./ matters.
  3. For an AppImage, right-click it, go to Properties → Permissions, turn on Allow executing file as program, then double-click it.

Once they're installed, the apps keep themselves up to date. You don't need to come back here for new versions.

Central Usage on iPhone and iPad

The App Store app isn't out yet. You can still use Central Usage from Safari, and it opens full screen like an app.

  1. Join the same Wi-Fi as the main admin's computer.
  2. In Safari, go to http://<main admin>:8095/cu/. The main admin can find the address in Central Control under Settings → This computer. If you have a Central Pedal, http://padpedal.local:8080/cu/ works too.
  3. Pick User 1 or User 2 and type the main admin's pairing PIN.
  4. Tap Share → Add to Home Screen. It'll always open the newest version.

Central Pedal

We test each pedal before it ships, and it arrives with its card in and its software on it. You don't need to download or flash anything.

Starting a new pedal
  1. Plug in the power and your audio outputs.
  2. On your phone, join the Wi-Fi called Central Pedal Setup. The setup page opens by itself. If it doesn't, go to http://10.42.0.1.
  3. Pick the church Wi-Fi and type its password.
  4. Type a 4-digit code. If you use Central Control, use the main admin's code. If not, any 4 digits will do, and Central Pedal Control will use the same one.
  5. Tap Upload. The pedal joins your Wi-Fi and it's ready to play.
Updating a pedal you already have

Connect it to the internet and open Settings. When Update ready shows up, press Install. Your songs and settings stay as they are.

If there's no internet where the pedal is, download central-control-source.zip, put it on a USB stick and use Settings → Update software from USB….

Keys, packs, the pedal and sound plans are on the Motion Audio website, along with the help guides. If something isn't working, write to us from any app under Help → Contact technical support, or from the website.
