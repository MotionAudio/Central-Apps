## Central 9.2.2: logos on Linux, and Central Control installs over the old desktop app

**Download:** https://motionaudio.github.io/Central-Apps/ · everything already installed updates itself when it opens.

### Logos on Linux
Central Control, Central Usage, Central Pedal Control and Central Services now show their logos in the app menu, the dock and the taskbar, the same logos as on the website.

- The logos were only in one very large size, which Linux menus skip. Each app now brings every size the menus use.
- Central Usage's window now joins its own dock icon instead of showing up as a separate, blank one.

### Central Control installs over the retired desktop app
Some computers still had the old Central Pedal desktop app from 8.2 (its package was called central-control, in the same /opt/Central Control folder). Installing Central Control stopped with "trying to overwrite". Now Central Control replaces that old app by itself. Settings and songs in your home folder are not touched.

On Linux, install or update with one line from the download page, for example:

```
curl -fsSL https://motionaudio.github.io/Central-Apps/install.sh | bash -s control
```
