## Central 9.3.5: Central Pedal's Settings on a big screen, MIDI ports, the touch screen list

**Download:** https://motionaudio.github.io/Central-Apps/ · everything already installed updates itself when it opens.

### Central Pedal
- **MIDI ports no longer multiply.** The pedal was opening its own MIDI ports as if they were devices, which made a
  new "RtMidiIn Client / RtMidiOut Client" port every few seconds (and could loop MIDI back into itself). Now only
  real devices are opened, shown by their own names ("Arturia KeyStep 32 MIDI 1"), and a long list scrolls.
- **Settings on an HDMI screen.** The cards pack together like a pinboard, each as tall as what's in it - no more big
  empty boxes next to a long card. The Stream Deck settings sit in a grid of short fields beside the keys.
- **Touch screen.** One tap for the common blue 3.5" screen on the pins ("XPT2046" on the back), then
  **Use this screen** and **Restart now**. The screen list is read the same whatever language the Pi is set to, and if
  it can't load, the card says why.
