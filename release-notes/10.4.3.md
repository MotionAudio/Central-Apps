## Central 10.4.3: the apps now talk to motionaudio.org

The Motion Audio website is open, so the apps now check their license keys there. Nothing else about how they work has changed.

### What's different
- **Keys are checked at motionaudio.org.** Central Control, Central Usage and Central Pedal Control check your key on the website when you enter it and when the app opens online. If you're offline, a key keeps working for 30 days.
- **The default keys still work.** If you're using one, you don't need to do anything. If that changes, I'll let you know before you need your own key.
- **The Central Pedal doesn't need a key,** same as before.
