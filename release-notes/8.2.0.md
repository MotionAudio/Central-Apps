## Central Pedal 8.2.0 · Central Control 2.2.0

**Download:** https://motionaudio.github.io/Central-Apps/ · everything already installed updates itself (it asks first).

### New names
- The Raspberry Pi app (and its PC version) is now **Central Pedal**. The companion app - Central Usage until now - is
  now **Central Control**. Your settings, songs and roles carry on. The installer files keep their old names
  (`central-control-…` is Central Pedal, `central-usage-…` is Central Control) so every install keeps updating itself.

### Pairing, set up by the main admin
- Set up the **main admin first**: its name, its **inputs and outputs** (when it is the sound desk), a 4-digit
  **pairing PIN** (e.g. 0915) and its own **role PIN** (for moving computers between user and admin).
- Every other device picks **Admin**, **User 1** or **User 2** and types the pairing PIN - that's all. The
  **Central Pedal** asks for the same PIN on its own screen (or takes the main admin's by itself when it has none yet).
- A computer set up as Admin without the role PIN waits; the main admin allows it on the Devices tab.
- Changing the pairing PIN later: devices online at the time switch over by themselves.

### For the main admin
- **Devices tab**: how many devices are connected, each one's role and jobs, and how its connection is doing - round
  trip to the pedal, in-ear buffer and dropouts, CPU, battery, version (good / fair / poor) - plus the pedal itself.
  **Change role**, Jobs, **Lock / Unlock**, Rename and Remove next to each one.
- **Your own job**: everything (production manager), or only what you run - e.g. lighting, when someone else has the cameras.
- **Service lock**: one button locks every device (or one at a time): the I/O tab, settings, fixtures, lighting
  outputs and video sources / streaming set-up close; everything used during the service keeps working.
- **Service tab**: up to **4 services**, each with its day and time, the roles it uses and a run order (songs from the
  setlist, welcome, announcements, sermon, prayer…) with minutes and the roles of each item. **Start / Next / Back / Stop.**

### For everyone
- **Your countdown** in the top bar: to the service, and to **your own next part** ("Lights: Sermon in 4:10",
  "Band: Song 2 in 1:30", "you're on"); a warning a minute before. Tap it for the run order with your parts marked.
  The stage display shows the service countdown too.
- **Manual lock** 🔓: lock your own computer so nothing you set changes (mix, chart, part, layout); hold 🔒 for
  2 seconds to unlock.
- **Talkback**: the main admin and mix / in-ear admins hold **TALK** (or tap to latch) to talk into everyone's
  in-ears or the ones picked, with the music dimmed; musicians have "Talk to the sound desk".
- **Recording** on the audio host: every input, the Central Pedal's tracks and a stereo program mix as WAV files,
  plus an MP3 of the program for the podcast - from the Mix tab, or automatically for a service with "Record it".

### Raspberry Pi
- **Faster start**: the screen no longer waits for the app before opening, no boot pause, and services the pedal
  doesn't use are off (applied when it updates).
