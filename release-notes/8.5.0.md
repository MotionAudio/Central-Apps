## Central Pedal 8.5.0 · Central Control 2.5.0 · Central Usage 2.5.0 · Central Pedal Control 8.5.0

**Download:** https://motionaudio.github.io/Central-Apps/ · everything already installed updates itself (it asks first).

### Four apps
| App | For | Runs on |
|---|---|---|
| **Central Pedal** | the pedal on stage | Raspberry Pi |
| **Central Pedal Control** *(new)* | getting the pedal ready anywhere, then uploading it | Mac (Apple Silicon, Intel); iPad coming to TestFlight |
| **Central Control** | the main admin and admins: lights, slides, lyrics, cameras, in-ears, tracks, mixing | Windows, Mac, Linux |
| **Central Usage** *(new)* | musicians and singers: chord chart, instrument, lyrics, their in-ear mix | Mac, Windows, Android; iPhone / iPad in Safari now, the App Store app once the Apple account is set up |

### Central Pedal Control: set it up anywhere, then Upload
- It is the same Central Pedal app, on your Mac. You can build the setlist and import tracks (MultiTracks.com / Loop
  Community downloads, your own WAVs). You can set up the pads, footswitches, knobs, MIDI, the instrument and your
  setups. The LIVE screen is there to rehearse.
- **⇪ Upload** (⌘U): type the pedal's name or address and its PIN, then tick what to send:
  - songs and their tracks
  - pads and sounds
  - buttons and MIDI
  - instrument
  - setups
  - colours
  - outputs and screens (only when they match the pedal's)

  Tracks go over as their original files.
- **On the Central Pedal**, a bar shows what arrived: **Apply now**, **Later** or **Discard**. It never applies while
  something plays.
- **⇩ Download** brings the pedal's songs and setup back to the Mac.

### Central Usage: the musicians' app
- It only offers **User 1 / User 2**. A device running it can't be made an admin, and the main admin's Devices tab
  shows which devices run it.
- **Android:** `CentralUsage-2.5.0.apk` is on the download page. It finds the main admin's computer on the Wi-Fi and
  opens Central Usage full screen.
- Musicians' laptops that already run Central Control keep working as User 1 / User 2. New ones should get Central
  Usage.

### Central Control
- Central Control is now the main admin's and admins' app: setting up a new computer offers **Main admin** and
  **Admin**. It points musicians to Central Usage.
- Its files keep their names (`central-usage-…`), so every install updates as before.
