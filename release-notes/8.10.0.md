### License keys and church accounts (ready, switched on when the website goes live)
**First open.** When an app first opens, it walks you through four steps:
1. **Internet.** On the Central Pedal, pick your Wi-Fi right there.
2. **Your production's name.**
3. **Your license key.**
4. **Your account.** Sign in or make one. Admins can all share one account; each user has their own.

**Keys** are 16 letters and digits, for example `P7K3-9QXM-2HDA-VW8F`:
- **P** keys are for Central Pedal and Central Pedal Control.
- **A** keys are for Central Control (admins).
- **U** keys are for Central Usage (users).

**One device at a time.** A key is checked on the Motion Audio website when you enter it, so it can't be used on
two devices. It is checked again whenever the app opens online, and it keeps working 30 days without internet.

**Release key.** Settings → License → **Release key** frees a key for another device. The main admin can release a
lost device's key on the website.

**A built pedal** comes with its P key already on it: the pedal fills it in when it first opens.

**The website** (Motion Audio):
- **Church accounts.** The main user makes the church. Admins and users join with its admin code or user code when
  they make an account.
- **Everyone in the church** sees how many P, A and U keys are left. The main admin and admins also see every key
  and the device it's on, and can release keys.
