**Central Control 7.1.0 · Central Usage 1.3.0 · Central Control for PC 7.1.0**

- The HDMI picture fits any monitor: native resolution, waits for slow monitors, picks up a monitor plugged in later, and Settings → Screens has resolution, zoom and edge settings
- A start-up screen that shows the version; the app opens on the tab you used last
- The Inter typeface everywhere; a cleaner lighting editor in Central Usage
- Proper text boxes (the PC app), pasted chord charts keep their lines, the Wi-Fi password is hidden
- Updates now come from this repository by themselves

**Install on a PC:** download `central-usage-1.3.0-amd64.deb` (and/or `central-control-7.1.0-amd64.deb`) below, then `sudo apt install ./central-usage-1.3.0-amd64.deb`.
**The Pi:** Settings → Software updates → Check now → Install (or build a new SD card with `build-image.sh` from the source).
