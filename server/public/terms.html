Last updated October 20, 2026

Accounts

  • Give a real email address and keep your password to yourself. Admins also keep their phone number current, because sign-in codes go to it.
  • You're responsible for what happens under your account. Tell us right away if you think someone else is using it.
  • A church or production has one main admin. The main admin controls the church's people, roles, keys and billing, and can hand the role to someone else.

License keys

  • A key is a license to use one app. You're not buying the software itself.
  • An admin key (A) works on one device at a time. A user key (U) or Pedal Control key (P) works on two devices of the same person, signed in with the same account. A pedal's own key works on that pedal.
  • Pedal Control keys (P), including a pedal's own key, get updates forever. Admin (A) and user (U) keys get ten full releases of updates, counted from the version that was out when they were bought. So a key bought at 9.4 gets updates through 10.4. Renewing a key costs $20 and adds another ten releases. When a key's updates run out, the app keeps working. It just won't install newer versions, and you never have to update to keep using it.
  • Keys belong to the church that bought them. The main admin and admins can move them between people and devices. Don't sell keys or share them outside your church.
  • Don't try to get around the key checks, or copy, change or resell the apps.

Payments and billing

  • Prices are in US dollars and are shown before you pay. Stripe processes the payment.
  • A church's purchases and subscription are billed to the church, in its name. The card on file stays with the church when the main admin changes. The main admin manages it under Billing.
  • Central Services is a monthly plan for the whole church. The price depends on how many accounts the church has, as shown on the website, and it changes as the church grows or shrinks. You can cancel any time under Billing.
  • A discount code takes a percentage off software: keys, packs and renewals. It doesn't apply to the built pedal or to monthly plans, and a church can use a given code once. A free trial code gives a church everything for the length of the trial. When it ends, the trial keys stop working and the apps ask for a bought key, but your songs, setlists and settings stay put. A church only gets one free trial.
  • The Central Tracks Unlimited subscription renews every month until it's cancelled. Cancel any time under Billing. It stays on until the end of the month you've paid for.
  • Refunds follow the refund policy.
