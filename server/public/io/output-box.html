Central I/O

Set up the Central I/O Output Box

16 outputs, for stems, in-ears or speakers. Coming 2028.

They're still being designed, so some details on these pages will change before they ship in 2028. Nothing here is for sale yet.

Before you start

You'll need a Central I/O Controller, because the output box gets its audio and its instructions from it. Setting up a box takes a few minutes.

Set up the rack version

  1. Turn the controller off.
  2. Set the output box on top of the controller or on top of another box, and push it back until it clicks onto the pins.
  3. Turn the controller on. It checks the new box and turns it on.
  4. In Central Control, open I/O. The new box shows up with its 16 outputs.

The pins carry the box's power and audio, so there's nothing else to plug in apart from the cables to your speakers, amps or in-ear packs.

Set up the standalone version

  1. Plug its power adapter into a wall outlet and into the box.
  2. Run a network cable from the box's network jack to the controller's network, either straight to the controller or through a network switch.
  3. In Central Control, open I/O. The box shows up with its 16 outputs.

Use it for the pedal

In Central Control, under I/O, pick an output and choose one of the pedal's channels for it, like Drums, Bass or Click. Each output can carry one channel. Run a cable from each output to the desk.

Use it for in-ears

In Central Control, open In-ears and pick this box for a mix. A stereo mix takes two outputs next to each other, so one box covers eight musicians. Plug wired in-ear packs or wireless transmitters into the outputs.

Use it for Central Wave

In the Central Wave tab, click a speaker on the room map and pick which output feeds it. Run each output to that speaker's amp or to a powered speaker. One box drives up to 16 speakers.

When something's wrong

If an output is silent, check its meter in Central Control under I/O. If the meter moves but you hear nothing, check the cable and the amp. If the meter doesn't move, check what's routed to that output.

If a standalone box doesn't show up, check that its light is on and that it's on the same network as the controller.

The other boxes: Central I/O Controller and Central I/O Input Box.
