Central I/O

Set up the Central I/O Output Box

8 outputs, for stems, in-ears or speakers. On Kickstarter in July 2027.

They're still being designed, so some details on these pages will change before they ship. All three boxes come out together on Kickstarter in July 2027, and Central Wave follows as a software addition in February 2028. Nothing here is for sale yet.

What it is

The output box is Central Output 8. It gives you 8 balanced line outputs on XLR jacks. The control box tells it what to play, so you set it up in Central Control rather than at the box.

It comes two ways. The rack version stacks on the control box with no cables between the boxes. The standalone version is the same box without the rack ears, with its own network jacks and USB-C power on the back, for wherever a stack can't reach.

These are renders of the case design, not photos. The details may still change before it ships.

Before you start

You'll need a Central I/O Control Box, because the output box gets its audio and its instructions from it. Setting up a box takes a few minutes.

Set up the rack version

  1. Turn the control box off.
  2. Set the box on top of the control box, or on another box, and push it back until it drops onto the pins. Up to 16 boxes stack on one control box, output and input boxes in any order.
  3. Turn the control box on. It counts the boxes, then turns them on one by one.
  4. Screw the box's ears to the rack.
  5. In Central Control, open I/O. The box shows up with its 8 outputs.

The pins carry the box's power and the network, so the only cables are the ones from the outputs to your desk, amps or in-ear packs.

Set up the standalone version

  1. Plug a USB-C charger into USB-C POWER. It has to do USB Power Delivery at 20 V, 25 W or more. Most laptop chargers do. A phone charger that only gives 5 V or 9 V won't, and the screen says POWER LOW.
  2. Run a network cable from NETWORK to the control box's BOXES jack, or to a network switch on it.
  3. To add another standalone box, run a cable from this box's THRU to the next box's NETWORK.
  4. In Central Control, open I/O. The box shows up with its 8 outputs.

The network jacks are etherCON, so a normal network cable plugs straight in, and a locking etherCON cable won't get pulled out on stage.

The screen

  • Top line: the box's name (you set it in Central Control), the network speed (1 GB is right) and its slot in the stack. A standalone box says STANDALONE.
  • Second line: what the control box is running (Pedal, In-Ears or Wave) and the clock. CLOCK LOCKED means the box is playing in time with the control box.
  • Meters: one for each output, with its label from Central Control, or its number if it hasn't got one. MUT on a meter means that output is muted.

The ID button

Press ID on the front and the screen and the green light next to the button flash for 10 seconds. The box flashes in Central Control too, so you can tell which box is which.

The green light stays on while the box is locked to the control box's clock and taking orders from it.

Route, label and mute the outputs

Everything is in Central Control under I/O.

  • Route an output: click it and pick what plays on it: a pedal channel, an in-ear mix, a speaker in Central Wave, or a source straight from another box.
  • Gain and mute: each output has its own gain, from -60 to +12 dB, and a Mute button.
  • Labels: name each output, like Main L or Wedge 1. The first 5 letters show under its meter on the box.

Use it for the pedal

Press Spread the pedal and every channel the pedal sends goes to the next output, across your boxes in stack order: box 1's 8 outputs, then box 2's. Pick a first output before you press it to start somewhere else. You can also pick an output and choose a channel for it, like Drums, Bass or Click. Run a cable from each output to the desk.

Use it for in-ears

In Central Control, open In-ears and pick this box for a mix. A stereo mix takes two outputs next to each other, so one box feeds four stereo packs, or eight mono ones. Plug wired in-ear packs or wireless transmitters into the outputs.

Use it for Central Wave

In the Central Wave tab, click a speaker on the room map and pick which output feeds it. Each output feeds one speaker or amp channel, so one box drives up to 8. Add boxes for bigger rooms.

When something's wrong

The screen saysWhat to do
NO NETWORK or NO LINKStandalone: check the cable in NETWORK, and that its other end is in the control box's BOXES jack. Rack: push the box back onto the pins.
WAITING FOR AN ADDRESSNothing on the network is handing out addresses yet. Check that the control box is on.
LOOKING FOR THE CONTROLLERThe box is on the network but hasn't heard from the control box. Check that the control box is on and on the same network.
NO CLOCK, CLOCK LISTENING or CLOCK SETTLINGThe box is finding the control box's clock. It should say CLOCK LOCKED within a few seconds. If it stays like this, check the network cable.
POWER LOWStandalone: use a USB-C charger that gives 20 V, 25 W or more. Rack: the control box's power is low, so check the control box.
  • An output is silent: look at its meter on the box and in Central Control. If the meter moves, check the cable and whatever it's plugged into. If it doesn't, check what's routed to that output and that it isn't muted.
  • A hum or buzz: these are balanced outputs, so use balanced cables (XLR or TRS) all the way to the amp or the desk.
  • A box doesn't show up in Central Control: press ID on it. If the screen doesn't flash, it has no power.
