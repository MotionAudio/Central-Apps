Boxes for more outputs, more inputs and every speaker in the room

Central I/O is three boxes I'm designing to go with the pedal and Central Control. The control box does the thinking, input boxes take 8 inputs each and output boxes give you 8 outputs each. The boxes are the same whatever you use them for. Only the control box's software changes, and there are three uses: The Pedal (more outputs from the pedal), The In-Ears (the band's in-ear mixes) and Central Wave (a mix for every speaker in the room).

What they're forRack or standalone

They're still being designed, so some details on these pages will change before they ship. All three boxes come out together on Kickstarter in July 2027, and Central Wave follows as a software addition in February 2028. Nothing here is for sale yet.

Three boxes

Every setup has one control box. Add as many input and output boxes as the room needs, up to 16.

Central I/O Control Box

On Kickstarter in July 2027

The brain. It runs The Pedal, The In-Ears or Central Wave.

The control box connects to your church network, your sound board and the pedal, and it decides what every other box does. It has a state-of-the-art chip inside and runs one of three programs: The Pedal, The In-Ears or Central Wave. It shapes each mix with our own plugins or VST3 plugins you've installed, and you can change any of it by hand. One long colour screen across the front shows what it's doing, every channel's level and how fast each network link is running.

How to set it up

Central I/O Input Box

On Kickstarter in July 2027

8 inputs, for mics, instruments and boards without AES67.

Each input box takes 8 inputs on combo jacks on the front, so you can plug in an XLR or a 1/4-inch cable. You set the gain, the pad and phantom power from Central Control. Most churches won't need one, because the control box can take the channels straight from an AES67 sound board (Dante boards in AES67 mode too). It's there for the band's mics and instruments on stage, and for boards that don't have a network card.

How to set it up

Central I/O Output Box

On Kickstarter in July 2027

8 outputs, for stems, in-ears or speakers.

Each output box (Central Output 8) adds 8 balanced outputs on XLR jacks. An output can carry one of the pedal's stems, an in-ear mix (stereo mixes use two) or the feed to one speaker. The control box tells each box what goes where, so you set it all up in Central Control instead of at the box.

How to set it up

Rack mount or standalone

Each box comes both ways.

Two versions

  • Rack mountThe rack boxes stack. Each one has a row of spring pins on top at the back, and pads underneath that land on the pins of the box below. The pins carry the power and one fast network link up through every box, so a stack needs no cables between the boxes, up to 16 of them. The control box goes at the bottom. It powers the whole stack and tells each box what it's for. Before it turns the power on it counts the boxes and checks the stack, so the pins don't spark when you set a box down.
  • StandaloneA standalone box has its own power and locking network jacks. The output box runs from a 20 V USB-C charger, like a laptop's; the others have a locking power adapter for a normal wall outlet. Use one where a stack can't reach, like beside the side-fill speakers or on the stage for the band's inputs. Run a network cable from it back to the control box, or chain it from another standalone box, and it shows up in Central Control like the rest.

You can mix the two. Keep a stack at the desk and put a standalone box wherever you need one.

That's a drawing, not a photo. The real boxes will look different.

What they're for

The same boxes do three jobs. Only the control box's software changes. Here's what each box does in each one.

The Pedal: more outputs for the pedal

The pedal has six outputs on the back. If you want each stem on its own channel at the desk, plug the pedal's I/O port into the control box and add output boxes.

  • Control BoxTakes every channel the pedal sends over one network cable, the stems, the click, the cues and the pads, and sends each one to the output you pick. One press spreads them across your boxes.
  • Output BoxGives you 8 more outputs per box. Put a stem, the click or the pads on each one and run them to the desk or the in-ear rack.
  • Input BoxYou won't need one for this.

The In-Ears: in-ears for the band

The control box builds the in-ear mixes. Each musician sets their own from Central Usage on their phone, and the output boxes send the mixes to the in-ear packs.

  • Control BoxMixes the board's channels and the pedal's tracks into up to 32 stereo in-ear mixes. Each one can have its own EQ, compressor and reverb, from our plugins or yours.
  • Output BoxFeeds the wired in-ear packs or the wireless transmitters. A stereo mix uses two outputs, so one box covers four musicians.
  • Input BoxBrings the stage mics and instruments in if you'd rather not take them from the board. With an AES67 board (or a Dante board in AES67 mode) you can skip it.

Central Wave: every speaker, every seat (a software addition, February 2028)

Central Wave gives each speaker in your room its own mix, timing and EQ, so the sound is even and clear from the front row to the back wall.

  • Control BoxYou place your speakers, subs and fills on a map of the room. Plug one to eight measurement mics into your sound board, and the control box listens to the room and sets each speaker. During the service it keeps listening and makes small changes, and anything it does you can change by hand.
  • Output BoxOne output per speaker or amp channel, so a box drives up to 8 speakers. Add boxes for bigger rooms.
  • Input BoxOnly needed if your board has no AES67. Then you plug the board's left and right, and any channels you want, into an input box instead.
