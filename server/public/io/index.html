Central I/O
Coming 2028

Boxes for more outputs, more inputs and every speaker in the room

Central I/O is a set of boxes I'm designing to go with the pedal and Central Control. The controller does the thinking. Output boxes give you 16 outputs each and input boxes take 16 inputs each. Use them to get more outputs out of the pedal, to run the band's in-ears, or to give every speaker in your room its own mix with Central Wave.

What they're forRack or standalone

They're still being designed, so some details on these pages will change before they ship in 2028. Nothing here is for sale yet.

Three boxes

Every setup has one controller. Add as many output and input boxes as the room needs.

Central I/O Controller

Coming 2028

The brain. It makes the in-ear mixes and runs Central Wave.

The controller connects to your church network, your sound board and the pedal, and it decides what every other box does. It runs a Raspberry Pi CM5 with 16 GB of memory, which is what lets it keep dozens of plugins running at once. It shapes each mix with our own plugins or VST3 plugins you've installed, and you can change any of it by hand.

How to set it up

Central I/O Output Box

Coming 2028

16 outputs, for stems, in-ears or speakers.

Each output box adds 16 balanced outputs. An output can carry one of the pedal's stems, an in-ear mix (stereo mixes use two) or the feed to one speaker. The controller tells each box what goes where, so you set it all up in Central Control instead of at the box.

How to set it up

Central I/O Input Box

Coming 2028

16 inputs, for mics, instruments and boards without Dante.

Each input box takes 16 inputs on combo jacks, so you can plug in an XLR or a 1/4-inch cable. You set the gain, the pad and phantom power from Central Control. Most churches won't need one, because the controller can take the channels straight from a Dante or AES67 sound board. It's there for the band's mics and instruments on stage, and for boards that don't have a network card.

How to set it up

Rack mount or standalone

Each box comes both ways.

Two versions

  • Rack mountThe rack boxes stack. Each one has six spring pins on top at the back, and pads underneath that land on the pins of the box below. Those six pins carry the power and all of the audio, so a stack needs no cables between the boxes. The controller goes at the bottom. It powers the whole stack and tells each box what it's for, and it's the only box in the stack with network jacks. It turns the power on only after it has checked the stack, so the pins don't spark when you set a box down.
  • StandaloneA standalone box has its own power adapter for a normal wall outlet and a locking network jack. Use one where a stack can't reach, like beside the side-fill speakers or on the stage for the band's inputs. Run a network cable from it back to the controller and it shows up in Central Control like the rest.

You can mix the two. Keep a stack at the desk and put a standalone box wherever you need one.

That's a drawing, not a photo. The real boxes will look different.

What they're for

The same boxes do three jobs. Here's what each box does in each one.

More outputs for the pedal

The pedal has six outputs on the back. If you want each stem on its own channel at the desk, plug the pedal's I/O port into the controller and add output boxes.

  • ControllerTakes every channel the pedal sends over one network cable, the stems, the click, the cues and the pads, and sends each one to the output you pick.
  • Output BoxGives you 16 more outputs per box. Put a stem, the click or the pads on each one and run them to the desk or the in-ear rack.
  • Input BoxYou won't need one for this.

In-ears for the band

The controller builds the in-ear mixes. Each musician sets their own from Central Usage on their phone, and the output boxes send the mixes to the in-ear packs.

  • ControllerMixes the board's channels and the pedal's tracks into up to 32 stereo in-ear mixes. Each one can have its own EQ, compressor and reverb, from our plugins or yours.
  • Output BoxFeeds the wired in-ear packs or the wireless transmitters. A stereo mix uses two outputs, so one box covers eight musicians.
  • Input BoxBrings the stage mics and instruments in if you'd rather not take them from the board. With a Dante or AES67 board you can skip it.

Central Wave: every speaker, every seat

Central Wave gives each speaker in your room its own mix, timing and EQ, so the sound is even and clear from the front row to the back wall. It's a tab in Central Control that stays off until you turn it on in Settings.

  • ControllerYou place your speakers, subs and fills on a map of the room. Plug one to eight measurement mics into your sound board, and the controller listens to the room and sets each speaker. During the service it keeps listening and makes small changes, and anything it does you can change by hand.
  • Output BoxOne output per speaker or amp channel, so a box drives up to 16 speakers. Add boxes for bigger rooms.
  • Input BoxOnly needed if your board has no Dante or AES67. Then you plug the board's left and right, and any channels you want, into an input box instead.
