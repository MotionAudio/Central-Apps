Central I/O

Set up the Central I/O Input Box

16 inputs, for mics, instruments and boards without Dante. Coming 2028.

Before you start

You'll need a Central I/O Controller, because the input box sends its audio to it. Most churches with a Dante or AES67 sound board won't need an input box at all.

Set up the rack version

  1. Turn the controller off.
  2. Set the input box on the stack and push it back until it clicks onto the pins.
  3. Turn the controller on. It checks the new box and turns it on.
  4. In Central Control, open I/O. The new box shows up with its 16 inputs.

Set up the standalone version

  1. Plug its power adapter into a wall outlet and into the box.
  2. Run a network cable from the box to the controller's network.
  3. Put the box on stage, near the mics and instruments it takes.
  4. In Central Control, open I/O. The box shows up with its 16 inputs.

Set the gain and phantom power

In Central Control, under I/O, click an input to set its gain and pad. Turn on 48 V phantom power only for condenser mics and DI boxes that need it. Speak or play into each one and set the gain so the meter peaks in the yellow, not the red.

Use it for the pedal

You don't need an input box for the pedal's outputs. If you want a mic or an instrument in the pedal's in-ear mixes, plug it into the input box and pick it as a channel in Central Control.

Use it for in-ears

Plug the stage mics and instruments into the input box. In Central Control, open In-ears and add those inputs to the mixes. The band hears them, and you can still send them to your sound board over the network.

Use it for Central Wave

If your sound board has no Dante or AES67, plug its left and right outputs, and any channels you want Central Wave to mix, into the input box. In the Central Wave tab, pick those inputs as the board's mix.

When something's wrong

If an input's meter doesn't move, check the cable and the gain. A condenser mic needs phantom power.

If you hear a hum, try the pad, check the cable, and move the cable away from power cords.
