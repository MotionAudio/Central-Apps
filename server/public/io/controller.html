Central I/O

Set up the Central I/O Controller

The brain. It makes the in-ear mixes and runs Central Wave. Coming 2028.

  2. Set up the rack version
  3. Set up the standalone version
  4. Connect the pedal
  5. Run the in-ears

They're still being designed, so some details on these pages will change before they ship in 2028. Nothing here is for sale yet.

Before you start

You'll need the controller, a network cable to your church network or your sound board's Dante network, and a computer with Central Control on it. Setting it up takes about fifteen minutes.

Set up the rack version

  1. Mount the controller at the bottom of your rack. Leave the space above it free for the boxes.
  2. Plug the power cord into the back and into the wall. Don't turn it on yet.
  3. Set each output box and input box on top, one at a time. Push each one back until it clicks onto the pins of the box below.
  4. Plug the jack marked NETWORK into your church network or the switch your sound board's Dante card uses.
  5. Turn the controller on. Its screen checks the stack and lists each box. Then it turns the boxes on, one at a time.
  6. Open Central Control and go to I/O. The controller and every box on it show up there.

If a box is missing from the list, turn the controller off, lift that box and set it down again so it clicks onto the pins.

Set up the standalone version

  1. Plug its power adapter into the wall and into the controller.
  2. Run a network cable from NETWORK to your church network or your board's Dante switch.
  3. Plug standalone output and input boxes into the same network.
  4. Open Central Control and go to I/O. The controller and its boxes show up there.

Connect the pedal

Run a network cable from the pedal's I/O port, on its right side, to the controller's jack marked PEDAL. In Central Control, under I/O, the pedal's channels show up as inputs to the controller. From there you can send any of them to any output box.

Run the in-ears

  1. In Central Control, open In-ears.
  2. Press Add a mix for each musician. Pick which output box and which two outputs each mix goes to.
  3. Choose the channels for each mix: the board's channels over Dante or AES67, the pedal's tracks and any input box channels.
  4. Each musician opens Central Usage on their phone and turns their own mix up or down.

Every mix can have its own EQ, compressor and reverb. Add them from the mix's plugin list. Our plugins are there, and so are any VST3 plugins installed on the controller.

Turn on Central Wave

  1. In Central Control, go to Settings → Central Wave and turn it on. A Central Wave tab appears.
  2. Draw your room, then place each speaker, sub and fill where it really hangs and point it where it really points.
  3. Tell it which output box output feeds each speaker.
  4. Plug your measurement mics into your sound board and send them to the controller over Dante or AES67. One mic works. Up to eight gives a better picture of the room.
  5. Press Measure the room. The controller plays test sounds through each speaker, listens, and sets each speaker's level, timing and EQ.
  6. Press Follow the service if you want it to keep listening and make small changes while the band plays.

Anything Central Wave sets, you can change. Click a speaker to change its level, delay or EQ yourself. Lock it and Central Wave leaves it alone.

When something's wrong

If the screen says a box didn't answer, turn the controller off and reseat that box on the pins. If it still doesn't show, try it in a different spot in the stack.

If Central Control can't find the controller, check that the cable is in NETWORK, not PEDAL, and that the computer is on the same network.

If there's no sound from the board's channels, check that your board's Dante or AES67 output is routed to the controller in your board's own software.

The other boxes: Central I/O Output Box and Central I/O Input Box.
